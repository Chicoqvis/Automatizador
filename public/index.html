MANUAL DE COMO GERAR O TOKEN

O token autoriza o Automatizador a criar issues no repositório escolhido, usando as permissões da sua conta.

1. Localize o repositório

Abra o repositório no GitHub. No endereço https://github.com/PROPRIETARIO/REPOSITORIO, copie as duas partes depois de github.com/. Exemplo: Chicoqvis/Automatizador. É esse formato que você informa no campo Repositório.

2. Gere um token fine-grained

  1. No GitHub, abra sua foto de perfil → Settings.
  2. No menu lateral, abra Developer settings → Personal access tokens → Fine-grained tokens.
  3. Clique em Generate new token, dê um nome e escolha uma validade.
  4. Em Resource owner, escolha o proprietário do repositório.
  5. Em Repository access, escolha Only select repositories e selecione apenas o repositório que vai conectar.
  6. Em Repository permissions, defina Issues como Read and write.
  7. Para adicionar issues a um GitHub Project ou mudar o status, conceda também Projects como Read and write.
  8. Clique em Generate token e copie o token. O GitHub só mostra o valor completo nessa etapa.

3. Conecte na ferramenta

Volte ao Automatizador, informe PROPRIETARIO/REPOSITORIO, cole o token e clique em Conectar repositório. O token não é exibido novamente e, na versão online, fica criptografado na sua conta.

Segurança: não envie seu token a ninguém nem o coloque em capturas de tela ou arquivos. Se for exposto, revogue-o nas configurações do GitHub e gere outro. Organizações podem exigir aprovação de um administrador.
